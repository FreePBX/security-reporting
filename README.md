# FreePBX Security Reporting

This repository is for reporting security vulnerabilities in the [FreePBX Project](/FreePBX) whether they be part of open or closed modules, the distro, or even underlying components that we should be made aware of in the form of friendly-reminders.

Please read our [Security Policy](/FreePBX/security-reporting/security/policy) and list of [Published Security Advisories](/FreePBX/security-reporting/security/advisories?state=published). You may also wish to subscribe to our [community forums security category](https://community.freepbx.org/c/blog/security/55) for further interaction with other members of the FreePBX security community.

All code contributions require a human to sign our [Contributor License Agreement](https://oss-cla.sangoma.com/FreePBX/security-reporting). If any generative artificial intelligence was used, then it must be disclosed in `Assisted-by:` comments per [standard Linux kernel contribution procedures](https://docs.kernel.org/process/coding-assistants.html) and *not* tags like `Co-authored-by:` **to reflect that you (the human!) are the sole and original author.**
